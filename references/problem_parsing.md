# 题目解析层

## 层级概述
本层级负责解析用户输入的数学建模问题，提取关键信息并创建题目数据记忆，为后续解题提供基础。

## 执行流程
### 1. 接收用户输入
- 接收用户提供的数学建模问题文本
- 确认问题类型：完整问题、部分问题、需要补充信息的问题

### 2. 提取核心信息
#### 2.1 问题重述
- 用自然语言重新描述问题，保持原意
- 识别问题的背景和应用场景
- 明确问题的具体要求和目标

#### 2.2 约束条件提取
- **等式约束**：识别所有等式约束条件
- **不等式约束**：识别所有不等式约束条件
- **隐式约束**：识别问题中隐含的约束条件

#### 2.3 决策变量识别
- 变量名称：确定每个变量的名称
- 变量符号：确定数学符号表示
- 变量类型：连续变量、离散变量、整数变量等
- 取值范围：变量的上下界或其他限制

#### 2.4 目标函数确定
- 最大化问题：确定需要最大化的指标
- 最小化问题：确定需要最小化的指标
- 多目标问题：识别多个目标函数及其权重

### 3. 问题分类
根据问题特征进行分类：
- **优化类问题**：线性规划、非线性规划、整数规划等
- **评价类问题**：综合评价、排序、决策等
- **预测类问题**：时间序列预测、回归预测等
- **统计类问题**：假设检验、方差分析等
- **其他类型**：分类、聚类、模拟等

### 4. 创建题目数据记忆
创建结构化的题目记忆文件，包含：
- problem_id: 问题唯一标识
- problem_type: 问题类型分类
- original_text: 原始问题文本
- restatement: 问题重述
- constraints: 约束条件（等式、不等式、隐式）
- variables: 变量列表（名称、符号、类型、范围、说明）
- objective: 目标函数（类型、函数描述、权重）
- subproblems: 子问题列表
- data_requirements: 数据需求列表
- assumptions: 初步假设列表

### 5. 验证解析结果
- 检查信息完整性：所有必要信息是否已提取
- 检查一致性：各部分信息是否相互一致
- 检查合理性：提取的信息是否符合常识
- 识别缺失信息：标记需要用户补充的信息

### 6. 输出解析结果
- 输出题目数据记忆文件
- 输出解析报告，说明提取的关键信息
- 列出任何需要澄清的问题
- 确认是否可以进入下一阶段

## 限制与禁止行为
1. 问题重述必须保持原意，禁止修改原始问题文本
2. 约束条件提取必须完整，禁止遗漏题目中的隐含约束
3. 决策变量识别必须准确，禁止添加题目中没有的变量
4. 目标函数确定必须正确，禁止混淆最大化与最小化目标

## 质量要求
1. 问题重述必须准确反映原意
2. 约束条件提取必须完整无遗漏
3. 决策变量识别必须准确
4. 目标函数确定必须正确
5. 解析结果必须可验证、可追溯

## 异常处理
1. **问题不完整**：提示用户补充缺失信息
2. **信息矛盾**：标记矛盾点并请求澄清
3. **无法分类**：提供可能的分类建议让用户选择
4. **编码问题**：确保使用UTF-8编码处理中文
