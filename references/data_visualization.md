# 数据可视化层

## 层级概述
本层级负责根据验证后的数据生成适当的可视化图表，确保图表在A4页面中清晰显示数据，避免生成无意义或重复的图表。

## 执行流程
### 1. 接收验证后的数据
- 读取数据分析层的验证结果和数据文件
- 确认数据已通过合理性检验

### 2. 确定可视化需求
- **题目要求分析**：检查题目是否明确要求特定图表类型
- **数据特点分析**：数据类型、维度、规模、关系
- **可视化目标**：展示趋势、比较分析、分布展示、关系揭示

### 3. 选择图表类型
- **基础图表**：折线图（趋势）、柱状图（对比）、散点图（相关性）、饼图（比例）、直方图（分布）
- **高级图表**：热力图（矩阵）、箱线图（异常值）、雷达图（多维度）、3D图（多变量）
- **组合策略**：避免重复、互补展示、页面适配

### 4. 图表设计规范
- **页面适配**：宽度≤16cm，高度适合A4页面，分辨率≥300DPI，PNG格式
- **学术规范**：标题清晰、坐标轴标签完整、图例完整、字体规范
- **数据展示**：数据密度合适、比例合适、颜色搭配、标注重点

### 5. 图表生成
- **独立代码生成**：为每个图表生成独立的Python代码
- **代码解耦要求**：独立文件、不修改原代码、通过数据文件接口获取数据

### 6. 图表验证
- **视觉验证**：清晰度检查、数据展示、格式规范
- **逻辑验证**：数据一致性、趋势正确性、比例准确性
- **重复检查**：避免重复图表、信息冗余、必要性评估

## 🚦 行为红线（绝对禁止）

### ❌ 绝对禁止行为
- ❌ 禁止修改原始数据文件：只能通过数据文件接口获取数据
- ❌ 禁止生成与数据不符的图表：图表必须真实反映数据特征
- ❌ 禁止生成无意义图表：每个图表必须有明确目的
- ❌ 禁止生成重复图表：信息冗余的图表必须合并或删除
- ❌ 禁止图表生图代码与数据处理耦合：必须独立文件、独立执行
- ❌ 禁止图表宽度超过 16cm：必须适配 A4 页面

### ✅ 必须执行行为
- ✅ 每个图表必须有明确的目的和意义
- ✅ 每个图表必须在 A4 页面中清晰显示（宽度≤16cm，分辨率≥300DPI）
- ✅ 每个图表必须有完整的标题、坐标轴标签、图例
- ✅ 每个图表必须生成独立的 Python 代码文件
- ✅ 图表代码必须通过数据文件接口获取数据，不直接修改原数据
- ✅ 生成后必须进行视觉验证和逻辑验证

## 质量校验清单
在完成可视化层前，必须逐项检查：

| 校验项 | 合格标准 | 不合格处理 |
|:---|:---|:---|
| 图表目的 | 每个图表有明确展示目标 | 删除无目的图表 |
| 页面适配 | 宽度≤16cm，分辨率≥300DPI | 调整尺寸参数 |
| 学术规范 | 标题/标签/图例完整 | 补充缺失元素 |
| 数据一致性 | 图表数据与源数据一致 | 检查数据读取逻辑 |
| 重复检查 | 无信息冗余的重复图表 | 合并或删除重复项 |
| 代码独立性 | 每个图表有独立代码文件 | 拆分代码 |

**任何一项校验不通过 → 必须修正后重新校验，禁止带病输出**

## 异常处理
1. **数据问题**：如数据不适合可视化，**返回数据分析层重新分析**
2. **图表错误**：如图表生成失败，记录错误并尝试修复，**最多重试 3 次**
3. **格式问题**：如图表不符合要求，调整参数重新生成
4. **重复检测**：如发现重复图表，**删除重复项并记录**
