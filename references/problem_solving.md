# 题目解答层

## 层级概述
本层级负责根据题目解析结果，按题目顺序逐题逐问进行解答，确保每个问题的解答独立且完整。


## 执行流程
### 1. 接收题目解析结果
- 读取`problem_data.json`文件
- 识别所有子问题和问题要求
- 确定解答顺序和依赖关系

### 1.1 读取模型库
- **必须读取**：`tools/model_library.md`
- 本文件包含可用的数学模型库和算法模板
- 题目解答层**必须在编写求解代码前读取此文件**

### 2. 按题目顺序解答
#### 2.1 问题1解答
- **创建独立工作目录**：`question1/`
- **生成独立代码文件**：`solution1.py`
- **独立运行求解**：执行代码获取结果
- **保存独立输出**：`result1.json`

#### 2.2 问题2解答
- **创建独立工作目录**：`question2/`
- **生成独立代码文件**：`solution2.py`
- **检查数据依赖**：如果问题2需要问题1的数据，则明确引用
- **独立运行求解**：执行代码获取结果
- **保存独立输出**：`result2.json`

#### 2.3 继续其他问题...
- 为每个问题创建独立的解答环境
- 确保代码和输出互不干扰
- 明确记录数据依赖关系

### 3. 代码生成规范
每个问题的代码应包含：
- 问题X解答代码
- 数据预处理：读取和清洗数据
- 模型定义：实现数学模型
- 求解算法：优化或计算过程
- 结果输出：保存为结构化格式
- 可视化（可选）：生成图表

### 4. 数据存储结构
每个问题的输出应包含：
- **计算结果**：主要求解结果
- **中间数据**：求解过程中的重要数据
- **状态信息**：求解状态、收敛情况等
- **错误信息**：如有错误，记录错误详情

### 5. 依赖管理
- **无依赖问题**：完全独立解答
- **有依赖问题**：明确标注依赖关系
  - 读取依赖问题的结果文件
  - 使用依赖问题的输出数据
  - 在代码注释中说明依赖关系

### 6. 验证解答结果
对每个问题的解答进行验证：
- **结果合理性**：检查结果是否在合理范围内
- **约束满足**：验证是否满足所有约束条件
- **目标优化**：检查目标函数是否达到最优
- **边界检查**：验证边界条件是否正确处理

## 限制与禁止行为
1. 禁止生成无法独立运行的代码或依赖其他问题的全局变量
2. 禁止修改其他问题的工作目录或结果文件
3. 禁止使用未经数据分析层验证的数据进行后续计算
4. 禁止串题，每个问题必须独立解答

## 质量要求
1. 每个问题的代码必须可独立运行
2. 结果必须保存为标准格式（JSON）
3. 代码必须有完整的注释和文档
4. 必须记录详细的运行日志
5. 解答结果必须可验证、可追溯

## 异常处理
1. **代码执行失败**：记录错误信息，尝试修复或标记
2. **结果不合理**：返回数据分析层进行数据分析
3. **依赖问题**：检查依赖数据是否可用
4. **资源不足**：优化代码或调整参数

```
├── question2/
│   ├── solution2.py      # 问题2的解答代码
│   ├── result2.json      # 问题2的解答结果
│   ├── data2.csv         # 问题2的数据（如有）
│   └── log2.txt          # 问题2的运行日志
└── ... 其他问题目录
```
