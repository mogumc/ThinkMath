# 数据分析层

## 层级概述
本层级负责统筹分析所有问题的解答数据，进行合理性检验，确保结果正确且一致。

## 执行流程
### 1. 收集所有解答结果
- 读取所有问题的结果文件（`result1.json`, `result2.json`, ...）
- 汇总所有问题的解答数据

### 2. 数据一致性检查
- **跨问题一致性**：检查不同问题间的数据是否一致
- **时间序列一致性**：检查时间连续性、步长和范围匹配
- **空间一致性**：检查坐标系统、空间范围和分辨率

### 3. 合理性分析
- **数值合理性**：范围检查、量级检查、比例检查
- **逻辑合理性**：因果关系、业务常识、物理约束
- **统计合理性**：分布检验、异常值检测、趋势分析

### 4. 异常数据识别
- **明显错误**：数值超出合理范围、逻辑矛盾、格式错误
- **潜在问题**：数据波动异常、结果不稳定、收敛性问题
- **系统性偏差**：系统性高估或低估、方向性错误

### 5. 生成分析报告
包含：数据概览、一致性检查结果、合理性评估、异常标记、改进建议

### 6. 决策与反馈
- **通过决策**：标记数据为"已验证"，传递给数据可视化层
- **重做决策**：生成重做指令，返回题目解答层重新解答

## 限制与禁止行为
1. 禁止修改原始解答结果文件，只进行读取和分析
2. 禁止忽略明显的数据异常，必须标记并生成修正建议
3. 禁止跳过一致性检查步骤，必须完成所有检查后才能做出决策

## 质量要求
1. 数据一致性检查必须全面
2. 合理性分析必须准确
3. 异常数据识别必须及时
4. 分析报告必须完整、可读

## 异常处理
1. **数据不一致**：标记不一致点并生成修正建议
2. **结果不合理**：分析不合理原因并提供改进方向
3. **无法验证**：说明无法验证的原因，建议人工检查
4. **系统错误**：记录系统错误并建议重启分析

## 文件存储结构
```
数据分析结果/
├── validation_report.md      # 数据验证报告
├── summary_statistics.json   # 汇总统计信息
├── consistency_check.json    # 一致性检查结果
├── anomaly_detection.json    # 异常检测结果
└── decision_record.json      # 决策记录
```
