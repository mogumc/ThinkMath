# ThinkMath - 数学建模全链路自动化执行Skill

## 项目介绍

ThinkMath 是一个数学建模全链路自动化执行skill，支持从问题输入到最终论文输出的完整闭环。当用户需要解决数学建模问题、生成Python求解代码、创建可视化图表或生成标准数学建模论文时使用此skill。

## 功能特点

1. **全链路自动化**：从问题解析到论文输出的完整流程
2. **六层架构**：清晰的层级划分，确保每个环节的专业性
3. **独立解答**：每个问题独立解答，避免串题
4. **质量控制**：数据异常自动检测，确保结果正确性
5. **标准论文**：使用cumcmthesis模板生成符合竞赛要求的论文

## 执行流程

当用户输入数学建模问题后，系统按以下六个层级顺序执行：

### 1. 题目解析层
- 接收问题文本，提取核心约束、变量定义和目标函数
- 识别问题类型，创建题目数据记忆

### 2. 题目解答层
- 按题目顺序逐题逐问解答
- 为每个问题创建独立的工作目录和代码文件

### 3. 数据分析层
- 收集解答结果，检查数据一致性
- 异常数据打回题目解答层重做

### 4. 数据可视化层
- 根据验证后的数据生成适当图表
- 生图代码与数据处理解耦

### 5. 论文编写层
- 使用cumcmthesis模板编写论文
- 整合所有解题结果、数据分析和图表

### 6. 论文检查层
- 检查论文排版，提供编译指导
- 用户手动确认PDF和日志

## 核心设计原则

1. **独立性原则**：每个问题独立解答，禁止串题
2. **层级隔离原则**：每个层级读取对应规范，禁止串层
3. **质量控制原则**：数据异常打回重做，论文检查用户确认

## 使用方法

### 安装与配置
1. 确保已安装必要的Python库（如scipy、pandas、matplotlib等）
2. 确保已安装LaTeX环境（推荐XeLaTeX）
3. 将ThinkMath skill集成到AI助手环境中

### 使用示例
用户只需输入数学建模问题，系统将自动执行完整流程：

```
用户输入：某城市需要建设一个物流中心，要求：
1. 建立数学模型确定物流中心的最佳位置
2. 考虑不同配送点的需求和距离
3. 最小化总运输成本
```

系统将自动执行：
- 题目解析：提取约束条件和目标函数
- 模型建立：使用线性规划或整数规划模型
- 代码生成：生成Python求解代码
- 结果分析：验证解的合理性和可行性
- 图表生成：创建可视化图表展示结果
- 论文输出：生成标准格式的数学建模论文

## 支持的数学模型

### 优化类模型
- 线性规划、非线性规划
- 整数规划、动态规划
- 遗传算法等智能优化算法

### 评价类模型
- 层次分析法（AHP）
- 熵权法、TOPSIS法
- 模糊综合评价

### 预测类模型
- 时间序列分析
- 回归分析
- 神经网络预测

### 统计类模型
- 假设检验、方差分析
- 相关性分析、主成分分析

## 论文模板

使用cumcmthesis模板，支持：
- 标准数学建模论文结构
- 中文和英文混合排版
- 数学公式、图表、算法环境
- BibTeX参考文献管理

## 技术栈

- **编程语言**：Python 3.x
- **数学计算**：NumPy、SciPy、Pandas
- **可视化**：Matplotlib、Seaborn、Plotly
- **机器学习**：Scikit-learn、TensorFlow/PyTorch（可选）
- **论文排版**：LaTeX（XeLaTeX）、cumcmthesis模板
